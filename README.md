<h1 align="center">Orlon Code</h1>

<p align="center">
  A standalone, open-source AI coding environment built for mobile.
</p>

<p align="center">
  Code • Build • Debug • Use AI agents — directly from your device.
</p>

## Features

- Fully standalone — no external computer required
- AI coding agents
- Built-in terminal
- Local project management
- Git support
- Android APK building
- Multiple AI models
- Plugin support
- Mobile-first interface

## Why Orlon Code?

Most mobile coding assistants depend on another computer or remote server.

Orlon Code is designed to run the development workflow directly on your device.

## Status

Orlon Code is currently in active development. Expect bugs and breaking changes while the first stable release is being built.
