# Orlon Code

### AI-powered development, directly from your phone.

**Standalone • Open Source • On-Device Builds • AI Agents**

Orlon Code is a free, open-source coding environment built for Android.

Run OpenCode, edit projects, use AI coding agents, execute terminal commands, and build Android applications directly from your phone with no external computer required.

</div>

---

## Overview

Orlon Code brings a complete AI-assisted development environment to Android.

Instead of depending on another computer, Orlon Code runs the development environment directly on your device.

Open projects, edit files, run commands, use AI agents, and build applications from anywhere.

---

## Features

### Standalone Development

Orlon Code runs directly on your Android device.

- No external computer required
- No remote development server required
- Local projects and files
- Local command execution
- ARM64 Android support
- On-device development environment

---

### AI Coding Agents

AI agents can work directly with your projects.

They can:

- Read project files
- Create and edit files
- Work across multiple files
- Understand project structure
- Execute terminal commands
- Inspect command output
- Debug errors
- Refactor code
- Assist with complete development tasks

Orlon Code is designed around agentic development rather than a simple AI chat interface.

---

### Multiple AI Models

Choose between multiple AI models depending on what you are working on.

Models can be used for:

- Coding
- Debugging
- Reasoning
- Planning
- Refactoring
- General development assistance

Orlon Code includes access to free AI models.

Cloud-based AI models require an internet connection.

## Android Development

Orlon Code can build Android applications directly on-device.

Supported development capabilities include:

- Android SDK tooling
- Gradle
- Gradle Wrapper support
- Java development
- Kotlin development
- Android project compilation
- Debug APK generation
- Build output
- Compiler logs
- Local APK generation

### Development Workflow

```text
Open Project
     ↓
Edit Code
     ↓
AI Agent
     ↓
Build
     ↓
Generate APK
```

The entire development workflow can run directly from your Android device.

## AI Build and Fix

Orlon Code is designed to make debugging and building faster with AI assistance.

The development workflow can combine build tools and AI agents:

```text
Write Code
    ↓
Build
    ↓
Inspect Errors
    ↓
Fix Code
```

This allows agents to understand build output and help resolve development issues inside the same workspace.
