# Orlon Code

### AI-powered coding, directly from your phone.

**Standalone • Open Source • Free Coding Agents**

Orlon Code is a free, open-source development environment for Android powered by **OpenCode**.

</div>

---

## Features

- Fully standalone on Android
- OpenCode running directly on-device
- AI coding agents
- Multiple free AI models
- Built-in terminal
- Local project and file management
- Git workflows
- Android SDK and Gradle support
- Build APKs directly on-device
- Compiler and build output
- Plugin support
- Mobile-first interface

---

## Build Android Apps On-Device

Orlon Code can compile Android projects directly from your phone.

```text
Edit → Build → Generate APK
```

Java, Kotlin, Gradle, Android SDK tooling, and local APK generation are supported.

---

## AI Development

AI agents can work directly with your codebase.

They can read and edit files, run commands, inspect errors, refactor code, and assist with development tasks across your project.

---

## Developer Tools

Orlon Code is designed to work with developer tools and integrations such as:

- Git
- ADB
- GitHub
- REA
- MCP
- Supabase
- JADX
- apktool
- Android development tools

---

## OpenCode

Orlon Code is built around **OpenCode**, the open-source AI coding agent, and brings it into a standalone mobile development environment.

Orlon Code is an independent project and is not affiliated with or endorsed by the OpenCode team.

Orlon Code is open source and welcomes contributions, bug reports, plugins, feature ideas, and improvements.
